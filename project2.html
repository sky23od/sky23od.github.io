MARIE Simulator Program

Description

This project was created for the course CGS 3269 (Computer Architecture Concepts). It is a MARIE assembly program that reads four positive integers (a, b, c, d), validates them, computes a × b and c × d using repeated addition loops, and then adds the two products to produce the final result.

Skills Learned

  • Assembly programming
  • MARIE architecture concepts
  • Loop constructs
  • Program control flow
